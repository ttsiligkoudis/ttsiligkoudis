### What I'm running

**[Watchario](https://watchario.app)** — a media tracker that keeps AniList, Kitsu, MyAnimeList
and Trakt in lockstep. One .NET 10 codebase serves a Blazor web app, a native Android and
Android TV client, a Stremio addon and a cross-browser extension, all on a public REST API of
213 documented endpoints. OAuth against four providers, concurrent write fan-out with
cross-provider normalisation, SQLite with continuous replication, idempotent billing webhooks,
two native video engines. Paying users, and nobody else on call.
→ [engineering case study](https://myportofolio.eu/watchario.html) ·
[issues & releases](https://github.com/ttsiligkoudis/watchario-app)

**[Sedulum](https://sedulum.com)** — multi-tenant appointment scheduling. Every customer is
provisioned its own subdomain with isolated data and per-tenant configuration. Infrastructure,
database, tenant model and settings layer designed from scratch.

**[Nomad Riders Go](https://nomadridersgo.fly.dev)** — route guide for a motorcycling channel,
on .NET MAUI Blazor and deployed to Fly.io, with the channel's latest uploads pulled live from
the YouTube Data API.
